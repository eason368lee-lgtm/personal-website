# Jun Lee — Publications

A minimal static publication site designed for scholarly discoverability.

## GitHub Pages

Enable GitHub Pages with:

**Settings → Pages → Deploy from a branch → main → / (root)**

The intended site URL is:

https://eason368lee-lgtm.github.io/personal-website/

## Paper pages

Each paper has a stable HTML page, exact title and author metadata, citation metadata, a direct citation PDF URL pointing to the corresponding Zenodo PDF, a visible abstract, a Zenodo record link, a canonical URL, robots.txt, and sitemap.xml.

Zenodo records:
- https://zenodo.org/records/23112673
- https://zenodo.org/records/23112883

The direct PDF URLs point to Zenodo so the repository does not need to duplicate the PDF binaries.
